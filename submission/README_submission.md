# 提交材料说明

本目录存放面向提交或老师审查的最终材料。

| 文件 | 说明 |
|---|---|
| `final_paper.pdf` | 最终论文 PDF |
| `final_7day_forecast.csv` | 最终连续预测结果 |
| `final_7day_forecast_integer.csv` | 最终整数化预测结果 |
| `ai_usage_record.md` | 辅助工具使用记录，仅在课程或竞赛要求披露时提交 |

最终预测表对应论文中的“低销量指数平滑 + 常规序列 Ridge”混合策略。若提交平台要求销量为整数，优先使用 `final_7day_forecast_integer.csv`。
