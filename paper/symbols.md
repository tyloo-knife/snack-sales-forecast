# 三、符号说明

| 符号 | 含义 | 单位 |
|------|------|------|
| $t$ | 日期序号 | 天 |
| $s$ | 门店编号 | - |
| $p$ | 商品编号 | - |
| $g$ | 商品类别 | - |
| $y_{s,p,t}$ | 门店 $s$、商品 $p$ 在日期 $t$ 的正向销量 | 件 |
| $\hat y_{s,p,t}$ | 对 $y_{s,p,t}$ 的预测值 | 件 |
| $Y_{t,g}$ | 日期 $t$ 类别 $g$ 的聚合销量 | 件 |
| $S_t$ | 指数平滑中的平滑水平 | 件 |
| $\alpha$ | 指数平滑系数 | - |
| $r_{pq}$ | 商品 $p$ 与商品 $q$ 的销量相关系数 | - |
| $X_t$ | 天气、节假日、活动日等外部变量 | - |
| $MAE$ | 平均绝对误差 | 件 |
| $RMSE$ | 均方根误差 | 件 |
| $WAPE$ | 加权绝对百分比误差 | - |
