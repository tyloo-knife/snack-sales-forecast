\section{数据字段与处理口径}

销售数据的核心字段包括日期、门店编号、门店名称、商品编号、商品名称、商品类别和销售数量。天气与日历数据的核心字段包括日期、天气类型、最高温、最低温、风力、工休日和活动日。本文以商品编号作为商品识别主键；同一商品编号下商品名称存在轻微差异时，以商品编号对应的合并商品为准。

为避免将损耗或冲销记录误解释为顾客购买需求，本文区分三类销量口径：
\begin{itemize}
  \item 正向销量：交易数量大于 0 的销售数量之和，是本文主要预测目标；
  \item 净销量：正向销售与负向调整相加后的结果，用于数据核对；
  \item 负向调整：交易数量小于 0 的记录，主要表示损耗、冲销或盘点调整。
\end{itemize}

数据预处理时不修改原始附件，也不删除原始交易记录。对建模表而言，负销量记录不进入正向购买需求目标，而是保留为负向调整字段；交易级极端值仅做标记，不在主口径中直接删除。天气字段中，“温度”和“温度.1”分别作为最高温和最低温处理。2022 年 4 月 1 日至 4 月 7 日没有真实未来天气和活动安排，最终预测采用历史同期外部变量情景，因此预测结果应理解为条件预测。

\section{核心算法伪代码}

\subsection{日销量面板构造}
\begin{enumerate}
  \item 读取销售明细，统一日期、门店、商品和类别字段；
  \item 按日期--门店--商品聚合正向销量、净销量和负向调整；
  \item 对历史中出现过的门店--商品组合补齐完整日期，缺失销量填 0；
  \item 按日期合并天气、节假日、周末和活动日字段；
  \item 输出供四个问题共同使用的日销量建模面板。
\end{enumerate}

\subsection{问题一短期预测}
\begin{enumerate}
  \item 分别构造门店、商品、门店--商品三个层级的日销量序列；
  \item 对每个序列计算 7 日移动平均、同星期均值和简单指数平滑预测；
  \item 使用时间顺序验证计算 MAE、RMSE 和 WAPE；
  \item 按层级选择误差表现稳定且解释清晰的主模型；
  \item 用主模型生成未来 7 天预测。
\end{enumerate}

\subsection{问题二类别聚合预测}
\begin{enumerate}
  \item 基于附件类别字段将商品销量聚合到类别层级；
  \item 计算商品销量相关系数，辅助描述商品之间的同步波动；
  \item 比较“单品预测后按类别加总”和“类别聚合后直接预测”两种方案；
  \item 选择类别聚合后直接预测作为同类零食预测主口径。
\end{enumerate}

\subsection{问题四严格 7 日递推验证}
\begin{enumerate}
  \item 设定多个连续 7 日验证窗口；
  \item 每个窗口只使用窗口起点之前的真实历史数据训练模型；
  \item 对窗口第 1 天生成预测；
  \item 从窗口第 2 天起，滞后项和滚动均值使用前序预测值递推更新；
  \item 汇总 7 天预测，计算各层级 MAE、RMSE 和 WAPE。
\end{enumerate}

\subsection{低销量混合策略}
\begin{enumerate}
  \item 在预测窗口起点前统计每个门店--商品组合的正销量天数占比、零销量比例和历史日均销量；
  \item 将极稀疏、低销量间歇需求或无正销量历史的组合划入低销量组；
  \item 低销量组使用问题一简单指数平滑预测；
  \item 常规组使用综合 Ridge 预测；
  \item 合并两部分结果，得到门店--商品粒度未来 7 天预测。
\end{enumerate}

\section{代码文件清单与复现顺序}

核心脚本按以下顺序运行：
\begin{enumerate}
  \item 数据读取与清洗：\path{src/data_loader.py}、\path{src/preprocessing.py}；
  \item 特征构造：\path{src/features.py}；
  \item 问题一图表重绘：\path{src/stage2_q1_figures.py}；
  \item Phase 3 结构补充与灵敏度分析：\path{src/stage6_phase3_structure_analysis.py}；
  \item Phase 4 文字论证补充证据：\path{src/stage7_phase4_text_evidence.py}；
  \item 问题二分析：\path{src/stage3_q2_analysis.py}；
  \item 问题三外部因素分析：\path{src/stage4_q3_analysis.py}；
  \item 问题四综合模型：\path{src/stage5_q4_analysis.py}；
  \item 严格 7 日递推验证：\path{src/stage5_q4_recursive_validation.py}；
  \item 问题四误差诊断与天气敏感性：\path{src/stage5_q4_error_diagnosis.py}、\path{src/stage5_q4_weather_sensitivity.py}；
  \item 消融检验：\path{src/stage5_q4_ablation.py}；
  \item 低销量策略：\path{src/stage5_q4_low_volume_strategy.py}；
  \item 显著性检验与最终混合预测：\path{src/stage5_q4_hybrid_final_forecast.py}、\path{src/stage5_q4_award_iteration.py}。
\end{enumerate}

主要输出文件包括阶段报告、误差表、图表和最终预测表。其中，问题三系数表保存为 \path{tables/q3_regression_coefficients_external.csv}，问题四显著性检验保存为 \path{tables/q4_significance_tests.csv}，最终整数汇总保存为 \path{outputs/q4_hybrid_forecast_7day_total_by_store_product.csv} 等文件。纸质稿不展示完整 Python 源码；完整代码保存在项目 \path{src/} 目录中。若提交平台要求电子附件，可同时提交最终预测明细 \path{outputs/final_7day_forecast_hybrid_low_volume_integer.csv} 和连续预测表 \path{outputs/final_7day_forecast_hybrid_low_volume.csv}。
