# 一、问题重述

## 1.1 问题背景

休闲零食连锁门店需要根据历史销售情况安排订货、库存和促销活动。不同门店的客流规模不同，不同商品的销量水平和波动性也不同；天气、节假日和门店活动等外部因素也可能与销量变化相关。因此，本题需要在构造清晰数据口径的基础上，分析历史销量规律，并预测未来 7 天销量。

## 1.2 需要解决的问题

1. 问题一：分析不同门店、不同零食的销量情况，分别预测未来 7 天总销量。
2. 问题二：分析同一门店内不同零食销量之间的联系，整合同类零食，并预测未来 7 天总销量。
3. 问题三：分析天气、节假日、活动日等因素与零食销量之间的统计关联。
4. 问题四：结合前三问模型和结论，预测各门店各种零食未来 7 天总销量，并与问题一、问题二模型比较。

## 1.3 数据说明

附件一为历史零售明细，字段包括门店编号、门店名称、商品代码、商品名称、数量、销售额、收款时间和类别名称等。附件二为天气、节假日和促销活动数据，字段包括日期、天气、最高温、最低温、风力、节日、活动日和工休日等。处理后数据见 `data/processed/daily_store_product_sales.csv` 和 `data/processed/modeling_base_table.csv`，字段说明见 `DATA_DICTIONARY.md`。
