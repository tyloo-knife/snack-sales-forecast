# 最终提交包说明

本目录为数学建模 A 题《休闲零食连锁店商品销量预测》的最终提交包。

## 文件说明

| 文件 | 说明 |
|---|---|
| `休闲零食连锁店商品销量预测.pdf` | 纸质友好版论文终稿，已压缩长源码附录，保留关键伪代码、结果表和预测汇总。 |
| `final_7day_forecast_integer.csv` | 推荐提交预测表，采用低销量指数平滑--常规 Ridge 混合策略，并按件数口径进行非负约束和四舍五入。 |

1. 原始数据未修改，本提交包不包含 `data/raw/`。
2. 本提交包不包含模型源码目录 `src/`、中间审查报告、LaTeX 临时文件、`.venv/` 或 Python 缓存。
3. 若竞赛平台要求件数口径，优先提交 `final_7day_forecast_integer.csv`。
4. 若竞赛平台允许连续预测值，可同时参考 `final_7day_forecast_raw.csv`。
5. AI 辅助使用说明已放在论文附录最后。
