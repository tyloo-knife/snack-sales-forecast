# 数据目录

## 结构

```
data/
├── raw/          # 原始数据（只读，不得修改）
└── processed/    # 清洗后数据
```

## 使用规则

1. **raw/ 目录只读**：上传的题目附件放在这里，之后不要修改或删除。
2. **processed/ 目录可写**：数据清洗脚本的输出放在这里。
3. **文件命名**：使用有意义的名称，如 `sales_2023.csv`、`products_info.xlsx`。
